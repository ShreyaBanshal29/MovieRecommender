# 🎬 Movie Recommender System

This is a content-based movie recommendation system built using *Python* and *Streamlit*. It allows users to select a movie and get recommendations for similar movies, along with real-time data like poster, genre, rating, description, and trailer fetched from the **TMDb API**.

---

## 🔍 Features

- 🎥 Recommend 5 similar movies using content-based filtering
- 🖼️ Display movie poster, genre, rating, and overview
- ▶️ Watch trailer directly via YouTube
- 📡 Real-time movie data from TMDb API
- 🧠 Cosine similarity on preprocessed metadata
- 💻 Clean Streamlit-based user interface

---

## 🛠️ Tech Stack

- **Frontend:** Streamlit
- **Backend:** Python, Pandas, Scikit-learn
- **API:** TMDb API
- **Data Handling:** Pickle, Pandas
- **Deployment:** Streamlit Cloud
- **Version Control:** Git, GitHub (with Git LFS for large files)
